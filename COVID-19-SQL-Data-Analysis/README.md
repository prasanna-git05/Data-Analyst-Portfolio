# 🦠 COVID-19 SQL Data Analysis

## 📌 Project Overview

This project analyzes global COVID-19 data using SQL. The analysis focuses on COVID-19 cases, deaths, infection rates, and vaccination trends across different countries and continents.

The datasets were imported into SQL Server, where SQL queries were used to explore and analyze the data.

---

## 🎯 Project Objectives

- Analyze COVID-19 cases and deaths
- Compare total cases with total deaths
- Analyze infection rates compared to population
- Identify countries with the highest infection rates
- Identify countries and continents with the highest death counts
- Analyze global COVID-19 numbers
- Analyze vaccination trends and the percentage of the population vaccinated

---

## 📊 Dataset

The project uses two datasets:

- **CovidDeaths.xlsx** – Contains information about COVID-19 cases, deaths, population, locations, and continents.
- **CovidVaccinations.xlsx** – Contains information about COVID-19 vaccination data.

### Project Workflow

**Excel Datasets → SQL Server → SQL Data Analysis**
